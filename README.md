# Campus Events

Навчальний застосунок «Події коледжу» на React Native, TypeScript та Expo SDK 57.

## Запуск

```powershell
npm ci
npx expo start
```

Для Android потрібна Expo Go, сумісна з SDK 57. Установлені залежності node_modules займають приблизно 514 МБ — вони потрібні для запуску, але не зберігаються в Git. Після очищення залежності відновлюються командою npm ci.

## Перевірки

```powershell
npx tsc --noEmit
npx expo lint
```

## Структура

- src/app — екрани та маршрути Expo Router.
- src/components — компоненти інтерфейсу, зокрема EventCard.
- src/data/events.ts — навчальні приклади подій.
- src/types/event.ts — тип EventItem.

Події є навчальними прикладами, а не офіційними анонсами.

Репозиторій: https://github.com/aemuw/campus-events

Це основна робоча папка проєкту. Методички, звіти та скріншоти зберігаються окремо в сусідніх папках pr1 і pr2.

## Практичні роботи

- ПР4: локальний банер БФКПЕП, керована форма, перевірка полів і формату дати, додавання подій у локальний стан.
- ПР5: FlatList, стабільні ключі, extraData для обраного, 1/2 колонки на порозі 700, локальне оновлення без дублікатів. Чернетка форми зберігається при зміні колонок.
- Потягніть список униз на телефоні або натисніть «Оновити події»: через 800 мс додаються дві демонстраційні події. Повторне оновлення їх не дублює.
- Події та обране зберігаються в пам’яті сеансу; після перезапуску повертаються початкові дані. Дата перевіряється за форматом, без календарної перевірки — відповідно до завдання.

Методички, звіти DOCX/PDF, скріншоти й результати перевірок зберігаються у сусідніх папках pr1–pr5. Нативне пакування перевірено; системну клавіатуру та жест оновлення потрібно перевірити на Android.
